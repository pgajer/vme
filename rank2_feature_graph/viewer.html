Geometric switch proportion

Geometric switch proportion = changes between displayed trajectory states / eligible consecutive observed-visit pairs. With m fully ordered, positioned observations, the denominator is m − 1. Motion along the same state interval counts 0.

Subject sorting chooses the merged reference core target used for ordering (60% initially). Both whole-sample ≥95% and within-pair ≥95% endpoint rules are on. Whole-sample ≥95% observations share one vertex state per leading taxon, regardless of neighboring pairs. Only within-pair endpoint squares can borrow a neighboring pair interval. The sorting target is independent of graph and trajectory settings. Export switching CSV includes every available target for the current participant list, in this order. Visit count counts observation records; the CSV also reports distinct ordered visits. Proportions use 0–1 and percentages use 0–100; unavailable scores are blank.

All released visits, including quality-flagged visits, are considered. Missing positions, ambiguous or repeated order, non-increasing measured time and episode changes exclude the affected adjacent pairs; no transition is joined across them. Gaps count once. This is a descriptive display-state score, not a rate per day or evidence of quasi-equilibrium.

Annotation key and scope

Only retained composition visits are shown, on the same time axis as the trajectory. Hover for values and source/date flags; click a marker to select its visit. Gaps between visits contain no inferred observations.

Bars / Sticks show Nugent and pH on separate subject-observed ranges with numeric ticks; compare values, not bar heights across subjects. Colors uses fixed light-to-dark blue scales: Nugent 0–10 and pH 0–14. Stress retains its fixed 1–5 color scale. Bleeding: light pink = spotting, medium pink = moderate, dark pink = heavy. Binary fields: filled teal square = explicit yes; open circle = explicit no. Partner type shows the original codes 1–3; no new classification is inferred.

Gray × = missing, not a negative. Gray open diamond = no bleeding entry although other diary fields are present; this is not confirmed absence of bleeding. Purple crossed diamond = invalid or suspected code, unavailable numerically; the raw value and reason remain on hover. Orange square outline = source date/quality flag or pending clarification (also shown for missing values); hover gives the reason. A black circle and vertical guide mark the selected visit. No recorded flag is not proof of error-free metadata.

In Abundance view, colored segment lengths are measured fractions of the entire sample; gray contains every other taxon. Each taxon keeps the same color across state rows and visits, matching its row label. Each state row has its own cumulative 0–100% scale from top to bottom. Whole-sample ≥95% takes precedence and creates one vertex row per taxon, regardless of neighboring pairs. This is a mass-qualified vertex state, not the definition of a top-1 CST. Bars retain measured abundance and are never snapped to 100%. Repeated observations at the same time are shown side by side within that time slot. Visits without a pair position remain in the optional context tracks and details. Density and interval fitting apply only to Pair position view.
Symbols and interval interpretationTaxon labels at the left mark the upper and lower ends of every interval in that row, including ≥95% squares. Horizontal endpoint guides connect the left taxon names to the right percentages: maximum whole-sample abundance within the displayed state reference, not the selected sample’s abundance. Short-interval labels use leader lines to separate overlapping names and percentages. These are taxon directions, not claims of 100% abundance at observed reference bounds. Interval length = observed pair-coordinate extent. Orange rings (when enabled): quality flags; hover for reasons. ○ Pair · ◇ original p2−p3 <2 pp · ■ ≥95% whole-sample rank 1 · □ ≥95% within-pair only (not rank 1). Filled squares share one vertex row per ≥95% whole-sample leading taxon, independent of neighboring pairs. Hollow within-pair squares use a compatible adjacent pair’s taxon end when available, otherwise their own interval. These are categorical placements, not measured t · × unavailable. Dashed bars retain reference intervals for unavailable positions. Dotted vertical guides beside short intervals are not to scale; the solid segment retains its true extent. Mass: 0% 100% (named pair; dominant feature for rank 1).

    Catalogue help

    Click a column heading to sort; click again to reverse. Counts and distances start largest first. Sorting keeps both filters. Export CSV saves these filtered rows in their current order, with full-precision distances and dataset context.

    Filter pair names: type any part of a taxon pair label, such as iners or gasseri. Matching ignores letter case and uses the entire text as one phrase. Clear it to remove the name filter.

    Endpoint distance (pp) is the Euclidean (L2) distance between the two observed full microbial compositions chosen as reference endpoints for that feature pair. Each endpoint attains its feature’s maximum relative abundance in the reference dataset. Differences across all features are measured in percentage points, squared, summed, then square-rooted. This is not the drawn 3D line length or the spread of samples within the state. Reference distances are retained across cohort and merged/pure views.

    Each face represents observations with the same unordered three leading positive taxa. Original rank order resolves abundance ties; observations with fewer than three positive taxa form no face.

    n is the count in the current population. Filter n and Filter % use the population chosen in the graph controls. The percentage denominator includes all its observations, even those without a face. Click headers to sort and type a taxon-name fragment to filter. Uncheck Show selected only to combine more triples using their checkboxes.

    Face eligibility is independent of rank-2 coverage and merged assignments. Dashed boundaries do not add top-2 CSTs. Export CSV preserves the displayed rows and order.
